# Criação de uma API

Este projeto foi desenvolvido com o objetivo de praticar desenvolvimento web utilizando consumo de API, organização de interface e manipulação de dados em JavaScript.

A ideia principal do sistema é simular uma loja de carros online, onde o usuário consegue visualizar veículos disponíveis de maneira dinâmica e moderna.



# Sobre o Projeto

O site apresenta veículos disponíveis diretamente através de uma API, trazendo informações como:

-  Nome do veículo
-  Marca
-  Valor
-  Ano

Tudo isso em uma interface simples, organizada e responsiva.


# Tecnologias Utilizadas

Durante o desenvolvimento utilizei:

- HTML5
- CSS3
- JavaScript
- Function


#  Objetivo do Projeto

Esse projeto foi criado principalmente para melhorar minhas habilidades em:

- Consumo de APIs
- Estruturação de páginas web
- Manipulação de JSON
- Responsividade
- Organização de código Front-End

Além disso, também serviu como prática para desenvolver projetos mais próximos de sistemas reais.
